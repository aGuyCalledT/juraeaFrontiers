Scope: the whole game client (web/index.html and web/src). Visitor mode: Experience (the visitor is inside the game).
Audience/job: website visitors playing a quick conquest match vs AI, hotseat or online, desktop and phone.
Constraints: static build; deterministic engine; English; reduced-motion respected.

## Direction contract
THESIS: A Catan-style tabletop of chunky cardboard hex tiles floating in a cartoon sea, where every Risk move is a little staged scene. Refuses the flat, gridded "strategy app" board with a sidebar of stats.
OWN-WORLD: Thick ink outlines (dark umber #2b1d14), visible tile thickness, saturated terrain (meadow green, pine green, slate mountains with snow caps, warm sand), teal sea with drifting foam. UI frames are carved wood planks with iron rivets and stone plaques, Kingdom-Rush chunky; display type Lilita One, UI type Fredoka. Faction colours: Necro violet + toxic green, Elves gold + leaf, Giants crimson + ember.
STORY: Player sees the island assemble, picks a faction, reads turn/phase from the banner, places troops, attacks with dice, fortifies, wins by toppling capitals.
FIRST VIEWPORT: Title: the island drops in tile by tile, centred, filling the screen; a carved wooden sign with the logo hangs top-centre; three faction shields sit on a plank tray at bottom with the start action. In game: board fills the viewport, a wooden top plank shows turn crest, resources and phase steps, the primary phase button sits bottom-right (thumb reach), shop/ability tray bottom-left.
FORM: Pinned by the owner. seed: none (pinned) — "It shall look like the game Siedler von Catan. Artstyle shall be cartoony and not to serious. Kingdom Rush can be an example for the artstyle."
SIGNATURE: Attack scene: an arc arrow draws from attacker to target, faction projectiles fly, a wooden dice tray slams in, dice tumble and resolve, losses pop as numbers, and a conquest plants a bouncing flag with a colour wipe. Motion grammar: squash-and-stretch drops with overshoot, ease-out settles, nothing linear.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
